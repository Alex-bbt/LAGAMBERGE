# Nav
La barre de navigation flottante : une pilule de verre collée en haut de l'écran, au-dessus du fond fluide.

- Classes `lg-glass lg-nav`, rayon `radius-pill`, position `sticky` à `space-4` du haut.
- À gauche le logotype `wordmark` ; à droite deux ou trois liens et le bouton principal « Collaborer ».
- Sur mobile, les liens passent dans un menu ; le bouton reste visible.
