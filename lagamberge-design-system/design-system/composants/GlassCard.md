# GlassCard
La surface de verre qui porte le contenu : blanc translucide, flou de 24 px, filet lumineux et ombre teintée bleu roi.

- `lg-glass` : verre standard (`glass-fill`), pour les cartes posées sur le fond fluide.
- `lg-glass--strong` : plus opaque (`glass-fill-strong`), pour les longs textes.
- `lg-glass--royal` : verre bleu roi, texte blanc. **Une seule par section**, pour le chiffre ou le message le plus fort.
- Rayon `radius-md` par défaut ; `radius-xl` pour un panneau pleine largeur.
- Toujours sur `Ambient` : sur un fond blanc uni, le verre n'a plus rien à laisser transparaître.
