# Chip
L'étiquette de chapitre : une pilule de verre avec un point bleu roi et un surtitre en capitales (`label`).

- Se place au-dessus de chaque titre de chapitre : « Chapitre 3 », « Prologue », « Épilogue ».
- Sert aussi pour les noms de marques partenaires, sans chiffres.
- Jamais plus de deux mots.
